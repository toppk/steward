# steward v0.2.4

## Features

None.

## Bug fixes

- **Btrfs subvolumes are indexed.** A root with `one_filesystem` (the
  default) skipped every subvolume beneath it, even within the same mount,
  so their contents went missing from the tree and totals. Only real mount
  points stop a scan now.
- **The index's write-ahead log no longer keeps its largest size for
  good.** Once it passes 64 MiB it is checkpointed and truncated at startup
  and after each scan. On upgrade, a large `index.db-wal` (2.6 GB seen)
  shrinks to nothing at the first start.
- **A folder that becomes a subvolume isn't reported offline.** Offline now
  means a folder fell back onto its parent's filesystem, as an unmounted
  volume does.

## Breaking changes

- Snapshots inside a root are subvolumes too, so they are now indexed. Add
  them to `exclude` (for example `.snapshots`) to leave them out.

## Upgrade notes

- `steward upgrade` (or `curl -fsSL https://toppk.github.io/steward/install.sh | sh`)
  installs it and restarts the service.

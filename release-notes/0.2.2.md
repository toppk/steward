# steward v0.2.2

## Features

- **Locate answers exact names at once.** A new index on names finds the
  entries named exactly what you typed in about a millisecond (instead of
  0.6 s per 14M entries); `locate` prints those first, then the other
  matches when the whole search is done. `locate -x` is instant. `--sort`
  prints one sorted list; the API's `locate` takes `stream`.
- **The desktop app's locate shows exact names at once,** then the full list.
- **Right-click menu in the desktop app's tree:** rescan a folder and
  everything below, rescan just the folder's own listing, show all copies of
  a file, copy a path.
- **`steward scan PATH --trust` reads PATH's own listing,** catching up a
  folder you just cleaned up without reading everything below; the API's
  `scan` takes `read_root`.

## Bug fixes

None.

## Breaking changes

- `steward locate` output is no longer one sorted list when piped: exact
  name matches come first. Add `--sort` where a script needs the old order.

## Upgrade notes

- The first start after upgrading builds the name index: about 20 s and about
  0.6 GB more index file for 14M entries. A first scan of a new root
  takes up to twice as long; daily rescans barely notice.
- `steward upgrade` (or `curl -fsSL https://toppk.github.io/steward/install.sh | sh`)
  installs it and restarts the service.

# steward v0.2.3

## Features

None.

## Bug fixes

- **`locate` really does print exact name matches at once.** In 0.2.2 the
  daemon held them back until the whole search finished, so they arrived
  with everything else; they now arrive in a few milliseconds.

## Breaking changes

None.

## Upgrade notes

- `steward upgrade` (or `curl -fsSL https://toppk.github.io/steward/install.sh | sh`)
  installs it and restarts the service.

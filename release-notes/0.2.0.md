# steward v0.2.0

## Features

- **Locate match modes.** `steward locate` keeps classic substring matching by
  default and adds `-x/--exact`, `-g/--glob`, `-r/--regex`, `-i/--ignore-case`
  and `-t/--type f|d|l|o` (e.g. `steward locate -x .git -t d`). The desktop
  app's locate field has the same choice (Contains, Exact, Glob, Regex, Aa).
- **Fresh locate results.** Results are confirmed on disk; the folders of any
  that have gone are rescanned and the search repeated, so renamed files show
  under their new names. `--check skip|warn|prompt|rescan` chooses
  (default `rescan`); the API's `locate` takes `check` too.
- **Python client:** `locate` gains `mode`, `ignore_case`, `kind` and `check`.

## Bug fixes

- Substring locate treated `_` and `%` as wildcards (`my_file` also matched
  `myXfile`).

## Breaking changes

None. The API's `locate` answers as before unless `check` is given.

## Upgrade notes

- `steward upgrade` installs it and restarts the service.

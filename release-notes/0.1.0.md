# steward v0.1.0

The first release: a per-user file index service for Linux, as one `steward`
command (command line and daemon) and the `steward-ui` desktop app.

## Features

- **Index.** Every path under your roots with its `lstat` fields and directory
  subtree totals (size, space on disk, files, directories, items), kept current
  by daily rescans that skip unchanged directories, without inotify. Volumes
  that are unmounted are reported offline, never as deleted.
- **Classification.** Git repositories, gitignored files, build output,
  dependency folders, virtualenvs, caches and trash, plus file categories.
- **Content ids.** The BitTorrent v2 (BEP 52) Merkle root of each file's bytes,
  kept across renames and moves; duplicates; BEP 52 piece layers derived
  without rereading files.
- **Application API.** JSON-RPC 2.0 on `content.socket` (resolve, inspect,
  verify, events) and `api.socket` (administration); a standard-library
  Python client.
- **Desktop app.** Tree by space or items, content ids and duplicates,
  settings editing, and the daemon's live state.
- **Operations.** `steward service install` runs the daemon as a systemd user
  service; `steward upgrade` installs new releases; levelled logging with
  journald priorities.

## Upgrade notes

- Install: `curl -fsSL https://toppk.github.io/steward/install.sh | sh`, then
  `steward service install`.
- An index built by a development version is upgraded in place on first start
  (totals are recomputed once).

# steward v0.2.1

## Features

- **Locate reports on stderr:** results, total time, time searching, checking
  on disk and rescanning, folders rescanned or queued, and whether the limit
  was reached. `-q` turns it off.
- **Locate results are sorted** by their bytes (`LC_ALL=C` order), names that
  aren't valid UTF-8 included.

## Bug fixes

None.

## Breaking changes

None. The API's checked `locate` answer gains `queued`, `limited`,
`search_ms`, `check_ms` and `rescan_ms`.

## Upgrade notes

- `steward upgrade` installs it and restarts the service.

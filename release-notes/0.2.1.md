# steward v0.2.1

## Features

- **Locate reports on stderr:** results, total time, time searching, checking
  on disk and rescanning, folders rescanned or queued, and whether the limit
  was reached. `-q` turns it off.
- **Locate results are sorted** by their bytes (`LC_ALL=C` order), names that
  aren't valid UTF-8 included.

## Bug fixes

- **File names that aren't UTF-8 are kept exactly.** They used to come out
  with `�` in place of the stray byte (so the path didn't exist), couldn't be
  sent in at all, and could crash the task reporting them in an event. Now
  every path travels as a JSON string with such bytes as `\udcXX` escapes
  (Python's surrogateescape); `steward locate` prints their raw bytes, and
  `tree` and `ls` show them as `\xAE`.

## Breaking changes

None for valid UTF-8 names (all but a handful). Names that aren't valid
UTF-8 now arrive as `\udcXX` escapes instead of `�`. The API's checked
`locate` answer gains `queued`, `limited`,
`search_ms`, `check_ms` and `rescan_ms`.

## Upgrade notes

- `steward upgrade` installs it and restarts the service.
